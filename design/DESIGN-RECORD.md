**判断修正（种子只是灵感，好看与可用优先）：**

1. 不做纯暗调 → 改为「纸本（亮）/ 暗房（暗）」双模。生产力工具白天也要用。
2. 等宽只给元数据层（编号、字段名、时间戳、wordmark），正文仍用 Noto Sans SC —— 中文没有可用的等宽字形，硬套会伤可读性。
3. 强调剂量按种子的「点缀」执行：全站只有「选中态」与「每栏至多一个主操作」能用胭脂色。

## 2. 方向与被否决项

**采用：印刷登记簿（Printed Ledger）** —— 灵感来自铅字印刷的报表台账、票据档案卡、暗房打样台。版本 = 台账里的一张登记卡；报头 = 墨黑通栏；分区之间 = 齿孔撕线；强调色 = 一枚胭脂印章。

| 被否决方向 | 原因 |
| --- | --- |
| 中心海报 · 衬线展示 | 展示型版式，和三栏工作台的功能布局冲突 |
| 不对称网格 · 怪诞无衬线 · 俏皮 | 橙/青互补 + 俏皮语气与「长时间干活」冲突，会抢编辑器的注意力 |
| 横向色带 · 窄体 | 编辑排版落到密集控件上显花，正文字重损失可读性 |

## 3. 评审历史

评审由**全新上下文的独立子代理**执行，每轮使用**同一份评审提示**（提示内不含停止阈值），只给设计事实、不给实现代码；每轮 2 位评审，取中位数。
偏差说明：本次没有走"只看截图"的路径（项目规则要求不做浏览器视觉验证，且本机无可用截图通道），改为给评审一份等价的「落地后的设计事实」清单。

| 轮 | 评分 A | 评分 B | 中位 | 主要反馈 | 本轮改动 |
| --- | --- | --- | --- | --- | --- |
| 1 | 6.5 | 6.5 | **6.5** | ① 所有卡片同一硬阴影 = 假层级 ② 两种红（印章红 / 语义红）撞色 ③ 打分控件 10 格实底抢戏 ④ 齿孔与噪点全站复用，装饰降级为壁纸 ⑤ 中文不吃 0.12em 宽字距 | 流内面板去阴影（阴影只给浮层）；齿孔全站只留报头一道；纸纹分两档；打分改淡胭脂底；语义红加深为 #8E2A14；字距降到 0.06em、字号 12px；侧栏改成一页台账（去卡套卡） |
| 2 | 6.8 | 7.4 | **7.1** | ① hover 与输入框明度差只有 4~6/255，等于不可见 ② 强调色三重超载（选中/主操作/命中底纹） ③ 圆角五档在屏上分辨不出 ④ 隐喻停在材料层，没落到网格 ⑤ 内容层级倒挂（正文与标签同字号） | 明度阶梯重排；命中高亮改墨色下划线；圆角砍到两档（面板 0 / 控件 2px）；纸纹只留桌面一层；画布记录行提到 13px 次级墨色 |
| 3 | 6.8 | 6.5 | **6.65** | ① 明度阶梯底部塌了：hover #E5DCCB 与桌面 #E7E1D6 只差 1.6 L*，非单调 ② 打分控件仍是强调色唯一成片铺开处 ③ hover 位移 1.5px 是半像素，1x 屏发糊 ④ 缺"正向签名"（账页横线 / folio 编号 / 字号事件） | 阶梯重标为严格单调（桌面 < 按下 < hover < 输入框 < 卡纸）；打分改胭脂描边不铺底；画布 hover 位移改 2px 整像素 |

**收敛判断：6.5 → 7.1 → 6.65，第二轮后不再上升，判定为收敛，停止迭代并向用户报告。** 剩余差距集中在版式层（网格 / 基线 / 编号系统）与"正向签名"，属于结构性改动而非参数调整，列入 §6 后续。

## 4. 减法清单（AI 痕迹检查表）

| 条目 | 处置 | 理由 / 位置 |
| --- | --- | --- |
| 左文右图英雄区 | 不适用 | 应用型界面，无落地页英雄区 |
| 三列图标特性卡 | 不适用 | 同上 |

| 多个强调色竞争 | 已处理 | 1 主色 + 中性 + 1 语义色；`tokens.js` |
| 卡片套卡片 | 已处理 | 侧栏合并为一页台账（表头 + 目录，发丝线分隔）；弹层内不再嵌套带框卡片 |
| 标题 emoji | 已删除 | `MainView.tsx` 空状态去掉 `👈` |
| 满屏毛玻璃 | 已删除 | 所有 `backdrop-blur` 移除（弹层遮罩、右键菜单、附件悬浮按钮、编辑器触屏按钮） |

| 长任务无反馈 | 既有 | WebDAV 备份/还原已有 loading 文案；本次未改动逻辑 |
| 焦点不可见 / div 冒充按钮 | 既有 | 统一 `focus-visible:ring-2`；`MinimalButton` 是唯一按钮原语 |

## 5. 状态与可访问性

| 项目 | 状态 |
| --- | --- |
| 对比度 | 三级文字（#23201B / #5F594D / #756D61）对卡纸 #FBF8F2 均 ≥ 4.5:1；胭脂对卡纸 5.4:1、对纸白 6.5:1；语义红 9.2:1 |
| 键盘与焦点 | 焦点环统一为 `ring-2 ring-primary/70`；打分控件是 `role="slider"` + 方向键；弹层 Esc 关闭 |
| 目标尺寸 | 图标按钮 36~40px；打分格高 40px |
| 减少动效 | `prefers-reduced-motion` 全局降级；新增位移均为 ≤ 2px |
| 四态 | 空（无项目 / 无版本 / 无备份）、错误（重复内容 / 删除失败）、加载（备份中 / 测试中）、成功（已连接）文案均为既有实现，本次只换皮肤 |
| 性能 | 静态 `background-image` 噪点，不参与动画与混合；弹层仍不用 backdrop-blur、不用入场 scale |

## 6. 后续（评审提出但本次未做）

1. **账页横线与基线网格**：画布 / 版本列表铺 8px 基线细线，规则线分级（报头下 2px、面板分隔 1px、元数据发丝线）。
2. **编号系统（folio）**：版本号 / 条目序号做成 20px+ 等宽大字压在卡片角上，把 11/12/13 的字号死区拉开成 11 / 13 / 20。
3. **暗房做真正的暗房**：安全灯单色（琥珀或红）当唯一光源，其余去饱和 —— 目前只是把色板提亮。
4. **让齿孔承担功能**：放到"已提交 / 草稿"的分界或可撕副券上，而不是只做报头的装饰。
5. 未被采纳的评审意见：**报头改为纸底**（评审 B 认为反白通栏是网页默认值）—— 保留墨黑报头，它是本设计最强的识别点，且齿孔撕线在它下沿才成立。
