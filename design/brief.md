# 设计简报：Prompt Studio · 印刷登记簿

> 品味批注优先：明确的「避免」比「想要」更能塑造结果。

## 1. 基本信息

| 字段 | 内容 |
| --- | --- |
| 产品与页面 | Prompt Studio —— AI 提示词的版本管理与编辑工作台（三栏：项目树 / 编辑器 / 版本画布 + 设置页） |
| 目标受众 | 自己与同行开发者；长时间、高频、连续使用，不是浏览一次就走的落地页 |
| 核心任务 | 在一个项目里改写出一版更好的提示词，并能找回、对比、评分任意一版 |
| 主行动 | ① 保存新版本 ② 在版本树中定位某一版 ③ 对比两版 |
| 交付范围 | 全站视觉语言（配色 / 字体 / 形状 / 组件观感）+ 画布渲染；动效沿用既有 token，不新增依赖 |

## 2. 方向

| 字段 | 内容 |
| --- | --- |
| 方向名称 | **印刷登记簿（Printed Ledger）** |
| 灵感源 | ① 铅字印刷的报表与台账：套红表头、细框线、油印纸的暖白 ② 票据与档案卡：齿孔撕线、编号栏、盖章处 ③ 暗房里的打样台：深底 + 一盏偏冷的灯 |
| 映射方式 | 每个版本 = 台账里的一张登记卡（框线卡片 + 等宽元数据）；项目树 = 台账目录；顶栏 = 报头的墨黑通栏；分区之间的分隔 = 票据齿孔撕线；强调色 = 一枚胭脂色的印章，只盖在「当前 / 选中 / 主操作」上 |
| 种子（仅存档） | `TlLhyV82yudMmwDCOhFRlIJfNR8uxHIg` |
| 种子解读摘要 | 主色相 336°（胭脂 / 印泥红）· 三分色 · 暗调 · 终端打印版式 · 等宽 · 票据齿孔母题 · 技术精确语气 · 点缀式强调 |
| 判断修正 | ① 不做纯暗调：生产力工具白天也要用，改为「纸本（亮）/ 暗房（暗）」双模，暗调是底色气质而非唯一模式 ② 等宽只用于编号、标签、元数据；正文与提示词内容仍用 Noto Sans SC（中文无可用等宽，硬套会伤可读性）③ 强调保持「点缀」剂量：全站只有选中态、主操作、链接三处能出现胭脂色 |

## 3. 品味批注

| 句式 | 内容 |
| --- | --- |
| 我想象的感觉 | 手指划过未漂白的纸，油墨压进纸面留下的轻微凹陷；翻台账时纸页边角相碰的声音；每个数字都对齐在同一条基线上 |
| 明确避免 | 紫色渐变、毛玻璃、发光与光晕、卡片套卡片、圆到发软的 12px 圆角、随机彩色高亮、标题 emoji、满屏同频的入场动画 |
| 取而代之 | 用**框线 + 纸面明度差**建立层级（而不是阴影和渐变）；用**2px 硬偏移阴影**表达"浮起"，像叠在一起的纸；用**等宽小标签 + 字距**表达"技术精确"，而不是加图标和色块 |
| 还缺什么 | 光有灰白会显得像没做完 —— 需要一枚**胭脂色的印章**提供记忆点，以及**纸纹**提供材质，让界面不像浏览器的默认底色 |

## 4. 约束

| 类型 | 内容 |
| --- | --- |
| 功能约束 | 它仍须作为工作台工作：三栏布局、可拖拽分隔条、Monaco 编辑器、Canvas 版本树、四个弹层的功能与快捷键一律不动 |
| 品牌约束 | 沿用 Material Symbols 图标与 Noto Sans SC；不新增字体与依赖（等宽用系统 mono 栈） |
| 技术约束 | React 18 + Tailwind 3（class 暗色）；颜色唯一来源是 `src/styles/tokens.js`，Canvas 与 Monaco 读不到 Tailwind，需各自同步；页面上有 Monaco + Canvas，很重，禁用全屏 backdrop-blur 与入场 scale |
| 可访问性 | 正文对比度 ≥ 4.5:1；全键盘可达；焦点环可见；目标尺寸 ≥ 24px；尊重 `prefers-reduced-motion` |

## 6. 成功标准

- [x] 结构、色彩、字体三项均与默认模板有本质区别（墨黑报头 / 暖白纸面 + 胭脂印章 / 等宽元数据层）
- [ ] 独立评审中位分 ≥ 9/10
- [ ] AI 痕迹检查表无未处理项
- [ ] 390 / 768 / 1440 通过；>2s 操作有反馈；四态齐全
- [x] M6 替代方案：主视觉不由渐变/色块充当，而由**纸纹材质 + 齿孔撕线 + 铅字排版**构成，并在浏览器中逐帧验证不产生额外重绘
